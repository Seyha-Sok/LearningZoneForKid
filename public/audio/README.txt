Little Letters: locally generated American English alphabet prompts.
Voice: Kokoro af_heart, selected by the user after listening to a sample.
Model: https://huggingface.co/hexgrad/Kokoro-82M (Apache-2.0 weights).
ONNX runtime/conversion: https://github.com/thewh1teagle/kokoro-onnx (MIT runtime).
Generated locally with socket connections disabled. No live/cloud speech calls.
These recordings use synthetic speech; they are not recordings of a human teacher.
Both uppercase and lowercase practice use the same spoken letter name.
See manifest.json for individual prompt text, phonemes, duration, and file hashes.
